# Lattice User Guide

Lattice is a LaTeX writing app for the Mac. Your paper stays an ordinary folder on disk; Lattice adds the PDF beside it, your papers and citations, version history, Overleaf sync and an AI agent.

This guide covers the main tasks, one page each. Lattice ships often, so the guide is updated with every release; **Help › What's New in Lattice** lists what changed in the version you run.

1. [Getting started](getting-started.md): install Lattice and TeX, open or create a project, the Get started checklist.
2. [Writing](writing.md): the editor, Source and Visual, the live PDF and jumping between them.
3. [Citations and papers](citations.md): `⌘⇧K` and `⌘⇧L`, the Papers library, Zotero.
4. [Building and fixing errors](building.md): `⌘S`, build problems, clean rebuilds, exporting.
5. [History and Compare versions](history.md): undo any change, save versions, compare two of them.
6. [Overleaf sync](overleaf.md): open an Overleaf project, upload one, how sync behaves.
7. [Boards](boards.md): Excalidraw whiteboards in your project.
8. [The Agent](agent.md): Claude Code, Codex or your own model, working on your paper.
9. [Plugins and themes](plugins-and-themes.md): Browse themes, install a plugin.
10. [Panels and workspaces](workspaces.md): arrange panels, save layouts, rename or delete a workspace.
11. [Settings and shortcuts](settings-and-shortcuts.md): where each setting lives, the keys worth learning.
12. [Troubleshooting](troubleshooting.md): what to try when something goes wrong, and how to report it.

Lattice's own menu opens this guide from **Help › User Guide**. 中文版：[Lattice 使用指南](zh-CN/README.md)。
