# Lattice 使用指南

Lattice 是一款 Mac 上的 LaTeX 写作应用。论文始终是磁盘上的普通文件夹；Lattice 在旁边加上 PDF、论文库与引用、版本历史、Overleaf 同步和 AI 助手。

本指南按任务分页，每页讲一件事。Lattice 更新频繁，指南会随每个版本一起更新；**帮助 › Lattice 新功能** 列出当前版本的改动。

1. [快速上手](getting-started.md)：安装 Lattice 和 TeX，打开或新建项目，「上手」清单。
2. [写作](writing.md)：编辑器、源码与可视化模式、实时 PDF 以及两者之间的跳转。
3. [引用与论文库](citations.md)：`⌘⇧K` 与 `⌘⇧L`、论文库、Zotero。
4. [编译与排错](building.md)：`⌘S`、编译问题、从头编译、导出。
5. [历史与版本对比](history.md)：撤回任何改动、保存版本、对比两个版本。
6. [Overleaf 同步](overleaf.md)：打开 Overleaf 项目、上传项目、同步规则。
7. [白板](boards.md)：项目里的 Excalidraw 白板。
8. [AI 助手](agent.md)：用 Claude Code、Codex 或自己的模型修改论文。
9. [插件与主题](plugins-and-themes.md)：浏览主题、安装插件。
10. [面板与工作区](workspaces.md)：排列面板、保存布局、重命名或删除工作区。
11. [设置与快捷键](settings-and-shortcuts.md)：每项设置在哪里、值得先记住的快捷键。
12. [常见问题](troubleshooting.md)：出问题时先试什么，以及如何报告。

## 开发插件

写给想制作插件或主题、并上架到 Lattice 市场的人。

13. [第一个插件](plugin-development.md)：做一个 hello-world 插件，从文件夹运行它，查看它的日志。
14. [插件清单与 API](plugin-reference.md)：权限、调用 Lattice、返回结果和操作。
15. [发布插件](plugin-publishing.md)：可复现的打包、向注册表提交 pull request、审核、签名、更新和紧急停用。
16. [制作主题](theme-development.md)：编写 `lattice-theme.json`，试用并发布。
