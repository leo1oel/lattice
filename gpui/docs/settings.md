# Settings

One of the features [the GPUI app](../README.md) has so far.

Settings (⌘,) has every section the Tauri app's has, in its order and with its product icons: Appearance (interface language, the interface size, notification position, interface sounds, both editors' type, the theme's appearance, tint, accent and code theme, translucency, the title bar's tools) and Editor & builds (keymap, your name, the automatic build, cleaning, the project's engine, shell escape and halt on error, the live preview); the Agent's Providers, MCP, Skills and Usage & limits (Synara's own settings pages, on one surface that switches section without reloading), Model endpoint (your own OpenAI-, Anthropic-, Responses- or Gemini-compatible API for Pi, its key in the keychain, a connection test, and the agent's restart, offered rather than made while a turn runs) and Environment (the proxy and provider variables the agent receives, and its restart); Overleaf and Literature services (whether adding a paper saves its full text, the OpenAlex, Semantic Scholar and Firecrawl keys with a test, the Crossref contact) under Integrations; the TeX doctor and Logs; and About › Acknowledgements (the core components, type, icons and sound, the origins, and every shipped package from the THIRD_PARTY_NOTICES.md the build embeds, searchable, a package's license texts or the whole file in a sheet over Settings, and the Timeless license in the PDF viewer in a build with those fonts).
Every page is searchable, applied as each choice is made, kept in `settings.json` and watched; the first run imports the Tauri app's own choices, the full-text choice among them, and the model endpoint and literature keys are the ones lattice-core keeps for both apps.
Lattice (the native app a writer on an Apple silicon Mac switched to from the classic one) adds Switch back to the classic version under Editor & builds › App updates: after a confirmation that the classic version opens with its data as it was before the switch and that changes made here don't flow back, it installs the classic release in place and restarts into it ([App updater](updater.md)).
Switching to the native app again later carries nothing over a second time but the recent projects (`lattice_settings::migrate::merge_recent_projects`): once the first launch's `tauri-migration.json` marker is there, a launch that finds the Tauri app's localStorage written since the marker last noted it joins the Tauri app's recent projects to its own, each folder once with the newer `openedAt`, newest first, at most eight. Its own entries are never dropped, so the Tauri app's fill only the room left. Settings, themes, plugins, the Overleaf session and the rest stay as the native app had them.
The interface size zooms every window as the Tauri app's webview zoom does (90% to 135%), from Settings, ⌘+ / ⌘= and ⌘− (with the size pill under the titlebar) and ⌘0, View ▸ Actual Size, Bigger and Smaller, and the palette.
Your name signs comments only when nothing else does: the open project's Git `user.name` signs ahead of it, then the Overleaf account signed in, so with either one the row says "Comments are signed {name}, from Git or Overleaf" and the field shows that name as its placeholder (read as Settings opens, where a writer goes after signing in).
Each section's product icon plays its gesture as the pointer comes onto its row, and rests on its last frame.
Interface sounds are the Tauri app's two cues, synthesized from the same Cuelume recipes, for a build the writer asked for and a running notice that settles.
Check spelling (`editorSpellcheck`, on by default, as in the Tauri app) marks misspelled words in the prose of `.tex`, `.md` and `.txt` files on macOS with the system's own NSSpellChecker, not Harper: only the lines on screen and a margin are checked, 350 ms after the last edit and once a scroll brings unchecked lines, in the language the system detects (Chinese prose is never marked), words in the project's dictionary are left alone, and a right-click on a marked word offers the checker's guesses, Ignore Spelling and Learn Spelling. Harper's grammar rules, the other languages' Hunspell dictionaries and the Project dictionary and Grammar rows are not in the GPUI app (on the 240 KB Ethereum Yellow Paper Harper held about 125 MB of the app's idle memory).
Translucency puts macOS's under-window vibrancy behind a frosted titlebar, gutters, Project and Papers, as the Tauri app does (off while Reduce transparency is on).

## In the e2e scenario

The `settings` module opens Settings with ⌘, (native keys), searches it and opens the row found with Enter, checks that a tint, an accent, a code theme and the editor's size apply at once, that the keymap turns Vim and Emacs on, that the interface switches to Simplified Chinese and back, that with Manual only builds an edit made outside the app reloads the open file and starts no build, that turning the Git tool off under Title bar tools takes its button out of the title bar and turning it on puts it back, that an edit to the settings file made outside the app applies, and that Escape closes it.
The `live_controls` module (`scenario/e2e/live_controls.rs`) checks Settings' live controls: the interface size with ⌘= / ⌘− / ⌘0 as native keys (the window's layout and scale, the size pill) and from Settings, interface sounds heard for a build the writer asked for and a running notice settling and not heard when off, and translucency's vibrancy and glass at each strength (or the reason there is none).
The `settings_pages` module (`scenario/e2e/settings_pages.rs`) opens each section the Tauri app lists and checks that it draws its page (Providers, MCP, Skills and Usage & limits on Synara's one surface, switched to their sections), that Settings search finds the agent, integration and build pages and reveals their rows, that with the full-text choice off a Zotero paper with a PDF is added with no PDF attached, and that Acknowledgements opens the third-party notices over Settings with Escape closing them before Settings.
