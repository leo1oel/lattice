# Getting a manuscript ready to send

One of the features [the GPUI app](../README.md) has so far.

Gets a manuscript ready to send, as the Tauri app does.
The TODOs tool panel (Manuscript TODOs in the palette, or the status bar's TODOs counter) opens as a tab of the documents' panel and lists every `% TODO`, `% FIXME`, `% XXX` and `\todo` under its file, each open editor's markers read from its buffer once typing settles; a row opens its line, and with none it shows the markers it looks for.
⇧F12 on a `\label`, a `\ref`-like command's label or a citation key in a `.tex` file lists every definition and reference in the bar under the titlebar, a row opening it; F2 (or the bar's Rename) renames it everywhere through lattice-core, the `.bib` entry and every `\cite` for a key.
Export for arXiv… (the palette) saves the open edits, then checks the pack the last build read: every figure included and spelled in the disk's case, the bibliography as a `.bbl`, a clean pdfLaTeX build of the pack alone, its `%` comments (removed or not, and the TODOs among them) and arXiv's size limit, with the files, what was left out and Remove % comments / Merge \input files; a warning never blocks Export ZIP, a failure does, and a project never built offers Build first.

The submission checklist (Submission checklist in the palette) opens as a tab of the documents' panel: the deadline counted down in Anywhere on Earth time, the verdict over a track with a segment per check, body words and main pages against budgets saved in the project, TODOs, unused labels and citations and the last build, the double-blind and PDF font checks under the venue whose template the paper loads, the writer's own materials and sign-offs (with the checklist templates menu beside them: a saved template's items added, any already listed by name skipped, and the list saved, replaced or removed as a template for the writer's other papers, kept as `submission-templates.json` in the app's state folder), and the word and page limits.

Its Figure inventory opens a sheet listing every literal `\includegraphics` under the image it draws, with each use's place, caption, labels (and any defined twice) and references; a card opens to preview the image with its pixel size and the DPI each use gives it, choose another project image, preview exactly which arguments change, and write them, each file only if it still holds the text the plan was made from; Undo replacement puts every written file back until another project opens.

## In the e2e scenario

Getting the manuscript ready to send (`scenario/e2e/submission.rs`): a TODO marker written into a chapter listed by the TODOs panel, opened as a tab of the documents' panel, its row opening the chapter; a label's definition and `\ref` listed by Find references, then the label renamed through the rename dialog and every `\ref` following it; and Export for arXiv checking the built fixture with no failing row and writing its ZIP; then a second window showing the project with the references listed and the export sheet open, which drops both when it opens another project. Then the submission checklist opened beside the documents with its disk checks read and a word budget saved in the manifest, and a chapter's figure listed by the figure inventory opened from the checklist, replaced by another project image keeping its options, and the replacement undone, and a checklist template's items added (a second time adding none) and the list saved as a template (`scenario/e2e/submission_checklist.rs`).
