# The TeX doctor and setup

One of the features [the GPUI app](../README.md) has so far.

The TeX doctor (Settings › TeX doctor, and in a sheet of its own from the palette), the setup wizard that installs BasicTeX (TeX Live on Windows) when a build finds no TeX, and the status bar's word counts (the manuscript's through TeXcount, this file's, the selection's) and its Annotations and TODOs counters (the open buffer's TODOs rescanned once typing pauses).
