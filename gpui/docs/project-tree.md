# The Project tree

One of the features [the GPUI app](../README.md) has so far.

Opens a project folder as the Tauri app does (a folder Lattice did not create is adopted the same way), with the Project tree on the left: the same files shown and hidden, a chain of single folders flattened into one row, New file, New folder, Import files…, Rename, a dragged row moved into a folder, ⌘C / ⌘V duplicating a row (⌘V with an image on the clipboard instead, or a folder's Paste clipboard image as figure, saving it into that folder as `clipboard-<time>.png` (a JPEG or WebP keeping its own extension), into `figures/` from the project root), Delete (of any file but the primary bibliography, where it says why), Set as main document, Show hidden files, and each changed file's Git status (its colour and letter, a dot on the folders above it).
