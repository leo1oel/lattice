# Markdown files

One of the features [the GPUI app](../README.md) has so far.

Opens a Markdown file as the Tauri app does, in Edit, Split and Preview (Split until another is chosen, one view for every `.md` file, in its strip and its ⋯ menu). Edit is its source, highlighted as the Tauri app's Markdown mode highlights it (tree-sitter-markdown's block and inline grammars with Lattice's queries, a fenced `latex` block as LaTeX). Preview is the Tauri app's visual editor, Lattice's own engine over TipTap, as a webview island over the panel's buffer: its toolbars, slash menu, find and replace, heading rail, KaTeX's maths, tables, task lists and footnotes are the engine's own; its images load through the island's asset protocol and an image pasted or dropped into it is saved under `figures/`; a link to a project file opens it and a web link the browser. The front matter stays outside the editor, and an edit lands in the file as the change it made and nothing else, so the rest of the file keeps its bytes; undo and redo are the buffer's, shared with the source; View in source puts the caret where it pointed, and a jump to a line in Preview lands in the visual editor. In Split each side follows the other through its blocks, as the Tauri app's Split does.
