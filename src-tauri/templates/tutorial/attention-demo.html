Computation

  1. Project token representations into query, key, and value spaces.
  2. Compare one query with every visible key using dot products.
  3. Scale the scores, then normalize them with softmax.
  4. Use the resulting weights to mix the value vectors.
A visualization is not a causal explanation. The matrix shows routing weights in one operation. Residual streams, value vectors, later layers, and the task objective also shape the final prediction.
